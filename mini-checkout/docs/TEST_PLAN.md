# QA Test Plan & Verification Report — FlipStore Checkout

**Application:** FlipStore Mini Checkout (Flipkart/Myntra E-Commerce Standard)  
**Test Runner:** Playwright (@playwright/test)  
**Execution Time:** 8.1 seconds  
**Test Suite Status:** 9 / 9 Passing (100% Green)

---

## 1. Quality Objectives

1. Validate the complete customer journey from catalog selection to order confirmation.
2. Verify strict dynamic arithmetic on derived line totals and overall order total in Indian Rupees (`₹`).
3. Ensure defensive input validation against empty carts, blank names, and whitespace strings.
4. Guarantee that customer inputs and cart contents are preserved upon validation failures.
5. Prevent duplicate orders under rapid double-click conditions using synchronous mutex locks.

---

## 2. Risk Matrix & Test Coverage

| Risk ID | Description | Severity | Likelihood | Mitigation Strategy | Test Coverage |
|---|---|---|---|---|---|
| **R1** | Duplicate order generated by double-clicking Place Order | Critical | High | Synchronous `useRef` lock blocks repeated triggers before state commits. | `TC-06` |
| **R2** | Checkout attempted with zero items in cart | High | High | Cart length guard blocks submission and shows error banner. | `TC-04` |
| **R3** | Name field filled with whitespace only | High | High | `.trim()` validation rejects blank strings. | `TC-02` |
| **R4** | Cart math desynchronization | High | Low | Dynamic calculation derived synchronously on each render. | `TC-03`, `TC-08` |
| **R5** | Cart state wiped on form validation error | Medium | Medium | Form validation logic is decoupled from cart state. | `TC-02`, `TC-04` |
| **R6** | Zero or negative item quantity allowed in cart | Medium | Low | `decrementQty` filters out items when quantity reaches 0. | `TC-05` |

## 4. Manual Test Scenarios

### Test 1: Empty Cart Submission
- **Input**: Enter "Rahul Verma" in Full Name without adding items.
- **Action**: Click "PLACE ORDER".
- **Result**: Red banner appears: `"Your cart is empty. Please add at least one item."` The name "Rahul Verma" remains in the input field. Checkout is blocked.

### Test 2: Double Click Idempotency
- **Input**: Add Wireless Mouse (₹799) and enter "Aryan".
- **Action**: Double-click "PLACE ORDER" within 100ms.
- **Result**: Synchronous ref lock triggers on click 1. A single order reference (`ORD-XXXXXX`) is rendered. Zero duplicate orders.

### Test 3: Whitespace Name Validation
- **Input**: Add Mechanical Keyboard (₹1,499) and enter `"   "` (spaces only).
- **Action**: Click "PLACE ORDER".
- **Result**: Blocked with `"Full Name is required."` The keyboard remains in the cart.
